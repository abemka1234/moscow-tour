# Москва глазами Артема
Небольшое Django приложение, которое содержит различные места, а также полную поддержку создание своих через удобную админ панель.
## Требования
 - Python 3.11.1
 - Установленые библиотеки из requirements.txt
 - OS: Windows/Linux/MacOS

## Установка

P.s: Туториал расписан для Windows
1. Скачайте репозиторий 
1. Перейдите в директорию с проектом 
1. Выполните эту команду
```
    pip install -r requirements.txt
```

4. Далее нужно заполнить .env файл
```
SECURE_SSL_REDIRECT=False
SESSION_COOKIE_SECURE=False
CSRF_COOKIE_SECURE=False
SECURE_HSTS_SECONDS=0

SECRET_KEY = 'секретный ключ'
DEBUG = True
```

5. Выполните комманду для создания пользователя в админ панели:
```
python manage.py createsuperuser
```

Все готово для загрузки мест в БД и запуска!

## Загрузка данных в БД

Есть 2 способа загрузить данные в БД:

1. Загрузить сформатированный JSON 
2. Вручную заполнить данные

Для первого способа:

1. Необходим JSON такого формата:
```
{
    "title": "Название",
    "imgs": [
        "Ссылка 1 на картинку",
        "Ссылка 2 на картинку"
    ],
    "description_short": "краткое описание",
    "description_long": "Длинное описание с содержанием HTML",
    "coordinates": {
        "lng": "Долгота",
        "lat": "Широта"
    }
}
```

2. Исполните команду  
```
python manage.py load_place ссылка_на_место_или_путь
```

Для второго способа:
1. Запустите сайт:
```
python manage.py runserver
```
2. Откройте в браузере (ссылку)[localhost:8000/admin].

3. Авторизуйтесь в пользователя, которого создали ранее.

4. Нажмите на кнопку Add у объекта Места в категории приложения [Core](http://127.0.0.1:8000/admin/core/place/add/).

5. Внесите данные места.

6. Нажмите кнопку Save.

## Запуск

1. Исполните команду  
```
python manage.py load_place ссылка_на_место_или_путь
```
2. Перейдите по [ссылке](http://127.0.0.1:8000/).

3. Все готово
